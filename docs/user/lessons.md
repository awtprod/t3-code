# Reviewed lessons

Open **Lessons** from the sidebar and choose an environment and Space. Lessons proposed from explicit Observation corrections appear as candidates. You can review the proposed rule, its Space or repository scope, confidence, expiry date, conflicting approved rule if one was selected, and the source correction before approving or rejecting it.

An approved lesson can be expired from the same page. Rejected and expired lessons remain visible in the review list, but are excluded from approved-memory retrieval. Lessons do not change Space policy or automation thresholds. It is fine for a Space to have no approved lessons.
