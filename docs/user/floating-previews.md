# Floating previews

Float a browser preview or device stream to keep it visible while you work in chat. Drag the **Move** handle to reposition it with a mouse, touch, or pen. Drag an edge or corner to resize it.

Use **Open preview in right panel** to dock the preview, or **Close floating preview** to clear it from chat. These controls are always available without hovering or tapping to reveal them. Browser previews also support a separate picture-in-picture window when available.
