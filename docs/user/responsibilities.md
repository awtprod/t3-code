# Responsibilities

Responsibilities show when an Automation last checked its source, whether it needs attention, and the latest inspectable result. A successful check can still have no useful result.

When a source adapter supplies a preparation result, the detail view shows the adapter-reported source version and observation time, selected/created/reconciled/skipped/failed counts, and any subject evidence and artifact IDs. These details describe prepared work; they do not approve a draft, send a message, or prove that an external outcome happened. If the adapter supplies no valid result, the view leaves preparation details empty.

Pause or resume a Responsibility from its detail view. A paused Responsibility does not change the underlying committed Automation definition. External actions continue to require their own authority and review.
